# XERJ vs BM25 + Seb: synthetic smoke test

2026-11-06. This is an exploratory 14-question smoke test, not the article benchmark or a statistically meaningful evaluation. Twelve synthetic records give heights for 12 people. Twelve questions compare known heights (six pairs, each asked in both orders); two ask about a missing person. Gold answers come from the numeric values. All data and gold are generated by `spike.py`.

- XERJ Query-1 rc.101, release bundle checksum verified, four model threads, local Apple arm64. Twelve source sentences and typed height facts were written to its local facts namespace. Read `final_status` and `final_answer`; `UNSUPPORTED` on an answerable case is a decline.
- SQLite FTS5 BM25 retrieves five single-sentence records using OR over name tokens and the words height and tall. Those hits and the same question are sent to Seb-9B-v2-NVFP4 as a three-way yes/no/unknown choice. Unlike XERJ, Seb receives explicit answer labels and instructions. This is a typed decision task; Seb is not a general open-ended answer generator.
- Scoring: a yes/no matching gold is correct; UNKNOWN is correct only when gold is unknown; UNSUPPORTED is a decline, not a correct answer. No inference failure or missing row is silently dropped.

Results: Seb 14/14 correct; XERJ 13/14 correct, 0 wrong, 1 unsupported (Luca Zee versus Kira Yun). Seb metering was 2,558 input tokens and 53,718 cost-nanos total: $0.003837 per 1,000 similar questions for inference alone. BM25 CPU and infrastructure are excluded. XERJ CPU cost was not measured in this run; median local wall time was 130 ms and cannot be converted to AWS compute cost without measuring CPU time and matching the instance. The article reports $0.042/1,000 on its different 5,000-fact workload and AWS pricing assumptions. Neither number includes fact extraction, indexing, idle capacity, storage or networking; the two per-1,000 prices are not a matched infrastructure comparison.

Files: `seb-results.json` is the raw live MCP response; `xerj-results.jsonl` contains the commit and complete per-question responses; `spike.py` generates both inputs and runs XERJ. `python3 spike.py prepare` prints the exact BM25 hits and question states. To rerun XERJ, start rc.101 with the verified model bundle on loopback port 19291 and an empty data directory, then run `python3 spike.py xerj`. Submit the generated states to Seb `seb_batch_decide` with model version `v2` and this shared question:

```json
{"answer":{"type":"choice","instructions":"Answer the question using only the evidence. Choose unknown if either person\u0027s height is missing. Compare the given heights.","criteria":{"yes":"The first person is taller.","no":"The first person is not taller.","unknown":"The evidence does not establish the answer."}}}
```

For a meaningful head-to-head, freeze an independent, varied dataset with lookup, comparison, counting, missing and conflicting data; test real corpus sizes; score correct, wrong, and abstained separately; capture actual metered tokens and CPU time; and include extraction and fixed hosting costs. The article’s reported benchmark data and scorer were not located in the public repository during this investigation.
